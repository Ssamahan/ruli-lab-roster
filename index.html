🔄 How the Claude sync works (2 minutes)
  1. Click 📋 Copy Claude sync prompt below.
  2. Open a Claude chat in the same conversation/project where your Training Tracker lives and paste the prompt — Claude reads the tracker and replies with a JSON block.
  3. Copy that JSON, come back here, paste it in the box below and press ⚡ Sync. Trainings appear instantly, attendees are blocked as TR, staff exits are applied, and a plan version is stored.

When this app itself is published as a Claude artifact, an extra 🤖 one-click sync button appears automatically (it uses Claude's built-in AI to structure whatever tracker text you paste). Direct background fetching of another artifact is blocked by Claude's security for all apps — this assisted sync is the closest possible integration.

🧭 One-time setup (~10 minutes, free forever for a lab this size)
  1. Go to console.firebase.google.com → sign in with any Google account → Add project → name it ruli-lab-roster (disable Analytics) → Create.
  2. In the project: Build → Realtime Database → Create database → choose Belgium (europe-west1) → start in locked mode.
  3. Open the database's Rules tab, replace everything with the rules below, press Publish:
    { "rules": { "labRoster": { ".read": true, ".write": "auth != null" } } } → anyone can view, only a signed-in manager can write. Enforced by Google's servers, not by this page.
  4. Build → Authentication → Get started → Email/Password → Enable. Then in the Users tab press Add user: your email + a strong password (this is your manager login).
  5. Click the ⚙️ gear → Project settings → under Your apps press the </> (web) icon → register app (no hosting) → copy the firebaseConfig = {...} object and paste it below.
